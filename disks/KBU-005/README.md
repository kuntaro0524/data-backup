### hirota：複合体構造の条件間比較

共同研究先ひろた氏のデータ。複合体構造の違いを整理して何らかの報告をした記憶があるが、過去の報告内容・所在は不明（実験者コメント）。

元の測定パスは `/user/target/Auto/2023A/BL32XU_230725_Hirota`。2023-07-25〜26の処理記録があり、`_kamoproc` は通常処理、`_kamo_30deg` は30°分割処理。BLEND・相関係数による複数条件のマージ結果がある。直下には処理結果のみで、参照先の生データはない。

**保存済みの解析結果**：MOLREPとREFMACによる分子置換・精密化のPDB、MTZ、ログがある。探索モデルはマウスCRY1複合体の6KX5（KL044）・6KX6（KL101）。これら参照PDBと今回の精密化結果を区別する。

| 結果 | 分解能 | 保存PDBのRwork / Rfree |
|---|---|---|
| `CPS1371-03` | 1.90 Å | 0.244 / 0.275 |
| `CPS1371-09` | 1.80 Å | 0.252 / 0.283 |
| TBOCマージ | 1.94 Å | 0.241 / 0.287 |
| AN174マージ | 2.21 Å | 0.253 / 0.297 |

**今回の予備比較（2026-11-04）**：

- 設定表ではTBOC=CPS1372、AN174=CPS1375の一部。正式な化合物名・濃度・対照条件の意味は未確認。
- 共通468残基のCαでTBOC対AN174のRMSDは0.874 Å。格子定数も異なる。
- 保存モデルにはリガンド・水がない。両データの既知KL044結合位置に正の差電子密度（参照原子位置で最大約+5.8σ / +5.5σ）を確認。**化合物結合を検証する候補であり、化学種や結合姿勢は未同定**。
- 451〜453番は密度を確認できるが結合ポケットから遠い。485〜492番はTBOC側の密度が弱く、大きな座標差を確実な構造変化とは判断できない。
- 既存モデル位相のマップを共通2.21 Åで比較した予備解析。新規の精密化・リガンドフィット・omit map検証は未実施。ピーク高から結合強度や占有率を比較しない。
