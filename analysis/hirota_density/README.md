# Hirota：TBOC / AN174 の予備比較

2026-11-04。KBU-005/hirota の既存モデル・反射データを読み取り比較した。HDD本体は変更していない。

## 結果

- 共同研究先ひろた氏の複合体構造解析データ（実験者説明）。元の測定パスは `/user/target/Auto/2023A/BL32XU_230725_Hirota`、処理記録は2023-07-25〜26。
- TBOCとAN174のマージ結果には、MOLREP・REFMACの解析ログ、jelly01.pdb / jelly01.mtz がある。
- 両方の保存モデルにはリガンド・水のHETATMがない。
- 6KX5のKL044位置を目印として重ねると、両条件の同部位にモデルで説明されていない正のFo-Fc密度がある。結合部位の候補として優先して確認する価値がある。
- ただし化合物名・濃度・対照条件の意味は未確認。正の密度だけでTBOC、AN174、KL044等の化学種、結合姿勢、占有率を同定していない。
- 全468残基のCαを一括重ね合わせしたRMSDは0.874 Å。モデル配列・原子構成は一致している。
- 451〜453番はCαの2Fo-Fc密度が両条件とも比較的高いが、既知KL044位置から約33 Å離れている。化合物結合による変化か、結晶内接触等の影響かは未判定。
- 485〜492番はTBOCの密度が弱い。特に一部のCαでは密度が負になり、大きな座標差を確実な構造変化として扱えない。既知KL044位置への最短距離は約13.4 Å。

## 電子密度の調査方法と数値

CCP4同梱Gemmi 0.6.2を使用。各jelly01.mtzのFWT/PHWTとDELFWT/PHDELWTからマップを計算した。
両方を2.21 Åでカットし、FFTのsample_rate=3。各マップを単位胞全体の平均0・標準偏差1に規格化した。
AN174は共通468個のCαによる剛体重ね合わせでTBOC座標系へ対応付けた。
6KX5 chain Aの共通463個のCαで既知KL044（DYR）を位置合わせした（RMSD 0.762 Å）。リガンドをデータにフィットしたわけではない。

| 指標 | TBOC | AN174 |
|---|---:|---:|
| 参照KL044の26原子位置のうちFo-Fc > +3σ | 11 | 8 |
| 同原子位置のFo-Fc最大値 | +5.82σ | +5.49σ |
| 451〜453番 Cα位置の平均2Fo-Fc | 2.16σ | 2.11σ |
| 485〜492番 Cα位置の平均2Fo-Fc | 0.98σ | 1.74σ |
| 485〜492番 Cα位置の最小2Fo-Fc | −0.83σ | 0.32σ |

これは原子位置の記述的なサンプリングであり、RSCC・正式なモデル検証・結合の有意性検定ではない。原子位置のサンプル数を独立した観測数として扱わない。
各マップのσはそれぞれの単位胞で規格化しているため、ピークの大小から直接占有率や結合強度を比較しない。
既存モデル位相によるマップで、独立したomit mapではない。格子が異なるため、単純な条件間Fo-Fo差マップは計算していない。
